# 📊 Excel Sales Analysis Project

## 📌 Project Overview

This project is an Excel-based Sales Analysis project designed to analyze sales performance using relational business data.

The dataset contains information about customers, orders, products, categories, employees, suppliers, and shippers. The goal is to transform the raw data into meaningful business insights and answer key sales-related questions.

## 🎯 Project Requirements

The project focuses on answering the following business questions:

1. 🏙️ Identify the **Top 4 Cities by Sales**.
2. 🏢 Identify the **Company with the Highest Sales**.
3. 📦 Identify the **Top 3 and Bottom 3 Categories by Sales** and explain the reasons behind their performance using date-related analysis.
4. 📅 Identify the **Highest and Lowest Sales Quarters**.

## 🗂️ Dataset Structure

The Excel workbook contains several related tables:

- **Customers** – Customer and company information.
- **Orders** – Order details, dates, customers, employees, shipping information, and freight.
- **OrdersDetails** – Products, quantities, unit prices, and discounts for each order.
- **Product** – Product information, prices, stock levels, suppliers, and categories.
- **Categories** – Product category information.
- **Employees** – Employee and sales representative information.
- **Suppliers** – Supplier and company information.
- **Shippers** – Shipping company information.
- **REQUIERMENTS** – Project analysis requirements and business questions.

## 🔗 Data Relationships

The tables are connected through key fields such as:

- `CustomerID`
- `OrderID`
- `ProductID`
- `CategoryID`
- `EmployeeID`
- `SupplierID`
- `ShipperID`

These relationships allow the data to be combined and analyzed to calculate sales performance across different dimensions.

## 🧮 Sales Analysis

Sales can be calculated using:

**Sales = Unit Price × Quantity × (1 − Discount)**

This calculation allows the project to evaluate sales by:

- City
- Company
- Category
- Product
- Quarter
- Date
